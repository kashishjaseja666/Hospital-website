# Hospital Website

A clean, responsive hospital website built by using html,css and js. It helps patients learn about the hospital , meet the doctors, read reviews, and get in touch easily.

Live Demo : https://kashishjaseja666.github.io/Hospital-website/

Technologies used: 
- HTML
- CSS
- JavaScript

How to Run locally:

1. Clone this repository
2. Open the project folder
3. Open the 'index.html' in your browser
